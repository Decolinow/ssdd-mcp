# Código de conduta

Seja respeitoso, objetivo e colaborativo. Críticas são sobre código, decisões e ideias, nunca sobre pessoas. Não toleramos assédio, discriminação, ataques pessoais ou exposição de dados privados de terceiros.

Quem mantém o projeto pode remover comentários, issues ou PRs que violem este código e restringir a participação de quem o descumprir repetidamente. Para reportar uma violação, use o relato privado do GitHub descrito em [SECURITY.md](SECURITY.md) ou contate quem mantém o repositório pelo perfil público.

Adaptado dos princípios do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
